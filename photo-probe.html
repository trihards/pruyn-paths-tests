Photo and file probe

Checks what this browser hands to a web page when you pick photos and files. Nothing leaves your phone: no upload, no server, no storage. When you're done, tap Copy results and paste them back. The copied text says only whether a photo had a location, never where.

1. Photos, as the editor asks today

Tap, choose Photo Library, pick 3 to 5 photos taken outdoors with Location on (at least one normal iPhone photo, ideally one Live Photo or screenshot too).

2. Photos, asking for HEIC by name

Same photos again, from Photo Library.

3. Photos through Files

Tap, choose Choose Files (or Browse), go to Recents or Photos and pick the same photos if you can. Skip if it's awkward.

4. A GPX file

Pick a GPX file from Files (for example one exported from AllTrails). If it shows greyed out and can't be tapped, note that, then try button 4b.

5. Sharing and saving

Share should open the iPhone share sheet with a file called probe-story.html. Save should offer a download to Files.
